Sobre o Projeto

Esta aplicação interativa permite que você gerencie suas tarefas de forma eficiente. Com ela, você pode adicionar novas tarefas, organizá-las em diferentes categorias e removê-las quando concluídas.

O To-Do List está dividido em três seções:

  • Projetos a Concluir: Aqui você adiciona novas tarefas que precisam ser realizadas.
  • Em Processo: Movimente as tarefas para cá quando estiver trabalhando nelas.
  • Concluídas: Após finalizar uma tarefa, mova-a para esta seção.

Utilize os botões para adicionar, mover e excluir tarefas conforme necessário. Dessa forma, você pode manter um controle mais preciso das suas atividades diárias.
