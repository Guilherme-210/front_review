Cadastro e Exibição de Alunos com JavaScript

O tema exolicação

Função: Adicionar um novo aluno à lista

js

const form = document.getElementById("form");

form.addEventListener("submit", function (ev) {
  ev.preventDefault(); // Evita o recarregamento da página

  // Captura dos valores dos inputs
  const aluno = {
    nome: document.getElementById("inputName").value,
    idade: document.getElementById("inputAge").value,
    materia: document.getElementById("inputMatter").value,
    tempo: document.getElementById("inputTemp").value,
  };

  alunos.push(aluno); // Adiciona o aluno ao array

  // Limpa os campos do formulário e foca no primeiro input
  form.reset();
  document.getElementById("inputName").focus();
});
  1. Evita o recarregamento da página (ev.preventDefault()) para manter os dados na tela.
  2. Coleta os valores dos inputs e cria um objeto aluno contendo nome, idade, matéria e tempo de estudos.
  3. Adiciona o aluno ao array alunos.
  4. Limpa os campos do formulário (form.reset()) e coloca o foco no primeiro input.
Função: Exibir os alunos cadastrados na textArea

js

const textArea = document.getElementById("textAlunos");
const pullButton = document.getElementById("pullButton");
const clearButton = document.getElementById("clearButton");

pullButton.addEventListener("click", function () {
  let texto = alunos.map(aluno => 
    `Nome: ${aluno.nome},\nIdade: ${aluno.idade},\nMatéria: ${aluno.materia},\nTempo de estudos: ${aluno.tempo}\n\n`
  ).join("");

  startLoading(); // Inicia a animação da barra de progresso

  setTimeout(() => {
    textArea.value += texto; // Exibe os dados no textarea
    clearButton.style.display = "inline-block"; // Exibe o botão "Apagar"
  }, 2000);
});
  1. Percorre o array alunos e cria uma string formatada com os dados de cada aluno.
  2. Inicia a animação da barra de progresso (startLoading()).
  3. Após 2 segundos (setTimeout), adiciona o texto na textArea.
  4. Torna o botão "Apagar" visível (clearButton.style.display = "inline-block").
Função: Limpar a textArea e ocultar o botão

js

clearButton.addEventListener("click", function () {
  textArea.value = ""; // Limpa a textArea
  clearButton.style.display = "none"; // Esconde o botão "Apagar"

  setTimeout(() => {
    document.getElementById("inputName").focus();
  }, 1000);
});
  • Apaga todo o conteúdo da textArea (textArea.value = "").
  • Oculta o botão "Apagar" (clearButton.style.display = "none").
  • Após 1 segundo, coloca o foco no primeiro input para facilitar a digitação.
Função: Criar uma animação de carregamento antes de exibir os alunos

js

function startLoading() {
  const progressBar = document.getElementById("progressBar");

  progressBar.style.background = "#007bff";
  progressBar.style.width = "0%";

  // Anima a barra de progresso
  setTimeout(() => {
    progressBar.style.width = "100%";
  }, 10);

  setTimeout(() => {
    progressBar.style.background = "#00ff00"; // Muda para verde ao concluir

    setTimeout(() => {
      progressBar.style.width = "0%";
    }, 500);

    setTimeout(() => {
      progressBar.style.background = "none";
    }, 1000);
  }, 2030);
}
  1. Inicia a barra com 0% de largura e cor azul (#007bff).
  2. Aumenta a largura da barra até 100% (efeito de carregamento).
  3. Após 2 segundos, muda a cor para verde (#00ff00) para indicar sucesso.
  4. Depois de 0,5s, reduz a largura para 0% e some com a barra.
