Template Literals no JavaScript

O que são Template Literals?

Os Template Literals (ou "Template Strings") são uma funcionalidade do ES6 que permite criar strings de forma mais flexível, utilizando crases (` `) em vez de aspas simples ou duplas.

exemplo de string normal 

const texto = `Esta é uma string
que possui múltiplas linhas
sem precisar de concatenação.`;
console.log(texto);

Usando Template Literals, podemos criar strings com múltiplas linhas sem precisar de caracteres especiais.

Quebra de Linha Facilitada 

const texto = `Esta é uma string
que possui múltiplas linhas
sem precisar de concatenação.`;
console.log(texto);

Usando Template Literals, podemos criar strings com múltiplas linhas sem precisar de caracteres especiais.

Adição facilitada de variaveis 

const nome = "João";
const idade = 25;

const mensagem = `Meu nome é ${nome} e eu tenho ${idade} anos.`;

console.log(mensagem);

No exemplo acima, usamos ${nome} e ${idade} para interpolar variáveis dentro da string.
