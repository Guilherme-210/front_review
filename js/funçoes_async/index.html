Funções Async

📌 Funções Async no JavaScript

No JavaScript moderno, funções async são uma forma elegante e mais legível de trabalhar com código assíncrono. Elas permitem que você use await para lidar com operações que retornam Promises sem precisar usar .then() e .catch(), tornando o código mais organizado e próximo do estilo síncrono.

🔹 1. O Que é uma Função Async?

Uma função async é uma função especial que sempre retorna uma Promise. Dentro dela, podemos usar await para esperar a resolução de outras Promises antes de continuar a execução do código.

📜 Sintaxe básica: 
async function minhaFuncao() {
  return "🚀 Função async executada!";
}

minhaFuncao().then(console.log); // 🚀 Função async executada!
  • async function minhaFuncao() → Declara uma função assíncrona.
  • O valor retornado ("🚀 Função async executada!") é automaticamente encapsulado em uma Promise.
  • .then(console.log) captura o resultado da Promise e imprime no console.
🔹 2. Tratamento de Erros com try...catch

Ao invés de usar .catch() para tratar erros, podemos envolver await dentro de um try...catch.

📜 Exemplo com erro: 
async function baixarArquivo() {
  try {
    throw new Error("❌ Erro no download!");
  } catch (erro) {
    console.error("⚠️ Capturado:", erro.message);
  }
}

baixarArquivo();

🔍 Aqui:

  • O throw new Error(...) simula um erro.
  • O bloco try...catch captura o erro e exibe a mensagem corretamente.

✔ Isso evita encadeamentos longos de .catch() e deixa o código mais organizado.

🔹 3. Como Usar Await Dentro de Funções Async

O operador await pausa a execução da função async até que a Promise seja resolvida, evitando a necessidade de .then().

O await so funciona dentro de funções Assíncronas

📜 Exemplo:Funções Assíncronas com await 
function esperar(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

async function executar() {
  console.log("⏳ Esperando...");
  await esperar(2000); // Aguarda 2 segundos
  console.log("✅ Concluído!");
}

executar();

🔍 O que acontece aqui?

  1. esperar(2000) cria uma Promise que resolve após 2 segundos.
  2. await esperar(2000) pausa a função até a Promise ser resolvida.
  3. Depois de 2 segundos, console.log("✅ Concluído!") é executado.

✔ Sem async/await, precisaríamos usar .then(), tornando o código menos legível.

📜 Exemplo: Execução Sequencial

Execução Sequencial: Quando você usa await em uma sequência de chamadas assíncronas, cada chamada espera a anterior ser concluída antes de prosseguir. Isso pode ser ineficiente se as operações não dependem umas das outras. 

async function exemplo() {
    const resultado1 = await operacao1(); // espera
    const resultado2 = await operacao2(); // espera
    // ...
}

🔍 Nesse caso, operacao2 só será chamada após operacao1 ser concluída.

📜 Exemplo: Execução Paralela Promise.all 
async function exemplo() {
    const promessa1 = operacao1(); // inicia a operação
    const promessa2 = operacao2(); // inicia a operação
    
    const [resultado1, resultado2] = await Promise.all([promessa1, promessa2]); // espera ambas
    // ...
}

🔍 Isso permite que operacao1 e operacao2 sejam executadas ao mesmo tempo, melhorando a eficiência.

🔹 4. Async Retorna Sempre uma Promise

Mesmo que uma função async pareça retornar um valor normal, ele sempre será encapsulado em uma Promise.

📜 Exemplo: 
async function respostaRapida() {
  return "✅ Tudo certo!";
}

console.log(respostaRapida()); // Promise { "✅ Tudo certo!" }

respostaRapida().then(console.log); // ✅ Tudo certo!

🔍 O que acontece aqui?

  • respostaRapida() retorna "✅ Tudo certo!", mas como a função é async, o retorno é uma Promise.
  • Para obter o valor, usamos .then(console.log).
🔹 5. Rejeitando Promises em Funções async

Se uma função async precisar indicar um erro, ela pode rejeitar uma Promise usando throw ou Promise.reject().

📌 Exemplo com throw: 
async function falhar() {
  throw new Error("❌ Algo deu errado!");
}

falhar()
  .then(console.log)  // Não será executado
  .catch((erro) => console.error("⚠️ Capturado:", erro.message));

🔍 Explicação:

  • O throw new Error("❌ Algo deu errado!") faz com que a Promise seja rejeitada.
  • Como falhar() retorna uma Promise rejeitada, o .catch() captura e exibe o erro.
📌 Exemplo com Promise.reject(): 
async function rejeitar() {
  return Promise.reject("🚨 Erro crítico!");
}

rejeitar().catch(console.error); // 🚨 Erro crítico!

🔍 Explicação:

Diferente do throw, o Promise.reject() rejeita explicitamente a Promise, sem precisar ser capturado por um try...catch.

📌 Rejeitando dentro de try...catch: 
async function buscarDados() {
  try {
    let resposta = await fetch("https://url-invalida.com");
    if (!resposta.ok) {
      throw new Error("Erro na requisição!");
    }
    let dados = await resposta.json();
    return dados;
  } catch (erro) {
    console.error("❌ Capturado:", erro.message);
    return Promise.reject(erro);
  }
}

buscarDados().catch(console.error);

🔍 Explicação:

  • Se a URL for inválida ou a resposta não for bem-sucedida, lançamos um erro.
  • O catch captura esse erro e pode rejeitar a Promise para que o erro seja tratado em outro local.
    • 🔹 6. Exemplo Real com API Fetch

    Funções async são muito usadas para fazer requisições HTTP com fetch().

    📜 Exemplo com fetch(): 
    async function buscarDados() {
  try {
    let resposta = await fetch("https://jsonplaceholder.typicode.com/posts/1");
    let dados = await resposta.json(); // Converte a resposta em JSON
    console.log("📄 Dados recebidos:", dados);
  } catch (erro) {
    console.error("❌ Erro na requisição:", erro);
  }
}

buscarDados();

    🔍 Explicação:

    1. fetch(url) retorna uma Promise com a resposta da requisição.
    2. await resposta.json() converte a resposta para JSON.
    3. O resultado é exibido no console.

    ✔ Com async/await, evitamos usar .then() várias vezes, deixando o código mais limpo.

    🚀 Conclusão
    Método Vantagens Desvantagens
    .then() e .catch() Funciona em qualquer Promise Pode deixar o código verboso e aninhado
    async/await Código mais limpo e legível Precisa de try...catch para erros
