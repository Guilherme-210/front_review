Tratamento de Erros no JavaScript

🛠️ Tratamento de Erros no JavaScript: try, catch e finally

O JavaScript, assim como outras linguagens de programação, permite lidar com erros de forma controlada usando blocos de tratamento de abordagens. Isso é essencial para evitar que um erro inesperado aconteça na execução do código.

O tratamento de erros no JavaScript é feito com:

  • try → Tente executar um bloco de código.
  • catch → Captura e lida com erros caso ocorram no try.
  • finally → (Opcional) Sempre execute um bloco de código, independentemente de ter ocorrido erro ou não.
⚡ Resumo
  1. ✔️ try → Tente executar um código que pode dar erro.
  2. ✔️ catch → Captura erros e impede que o código quebre.
  3. ✔️ finally → Sempre é executado (com ou sem erro).
  4. ✔️ throw → Lançamento de erros personalizados.
  5. ✔️ Os erros podem ser de diferentes tipos ( ReferenceError, TypeError, etc.).
🎯 1. O Problema Sem Tratamento de Erros

Quando um erro ocorre no JavaScript, ele pode interromper completamente a execução do código.

📜 Exemplo: 
console.log("Início do código...");

let resultado = 10 / 2;
console.log("Resultado:", resultado);

let erro = x + 10; // ❌ ERRO: 'x' não está definido.

console.log("Este código nunca será executado.");

💥 Erro no Console:

ReferenceError: x is not defined

O erro faz com que o restante do código não seja executado. Para evitar isso, usamos try...catch.

🛡️ 2. Como funciona try...catch?

O try executa um bloco de código. Se ocorrer um erro, ele pula para o catch, que captura a exceção sem quebrar o código.

📜 Exemplo: try...catch 
console.log("Início do código...")
try {
  let resultado = 10 / 2
  console.log("Resultado:", resultado)

  let erro = x + 10 // ❌ ERRO: 'x' não está definido.

  console.log("Este código não será executado.")
} catch (erro) {
  console.log("⚠️ Ocorreu um erro:", erro.message)
}
console.log("O código continua normalmente! 🚀")

🔹 Saída sem console:

// Início do código...
// Resultado: 5
// ⚠️ Ocorreu um erro: x is not defined
// O código continua normalmente! 🚀

✔️ O erro foi capturado sem quebrar o programa.

🔍 3. O Objeto de Erro (Error)

O catchrecebe um objeto com informações de erro, como:

  • erro.message → Mensagem de erro.
  • erro.name → Tipo do erro ( ReferenceError, TypeError, etc.).
  • erro.stack → Rastreamento de pilha (rastreamento de erro).
📜 Exemplo: 
try {
  let resultado = x / 2 // ❌ ERRO: 'x' não está definido.
} catch (erro) {
  console.log("Nome do erro:", erro.name)
  console.log("Mensagem:", erro.message)
  console.log("Stack trace:", erro.stack)
}

🔹 Saída:

// Nome do erro: ReferenceError
// Mensagem: x is not defined
// Stack trace: ReferenceError: x is not defined
//     at <anonymous>:2:19

🔁 4. O Blocofinally

O finallyé um bloco que sempre será executado, independentemente de ocorrer erro ou não. Ele é útil para fechar conexões, liberar memória ou limpar dados temporariamente.

📜 Exemplo: 
try {
  console.log("Tentando executar o código...")
  let resultado = 10 / 0 // Isso resulta em Infinity, mas não é um erro.
  console.log("Resultado:", resultado)
} catch (erro) {
  console.log("Erro capturado:", erro.message)
} finally {
  console.log("Isso sempre será executado! ✅")
}
console.log("Fim do código!")

🔹 Saída:

// Tentando executar o código...
// Resultado: Infinity
// Isso sempre será executado! ✅
// Fim do código!

Mesmo sem erro, finally foi executado

⚙️ 5. Criando Erros Personalizados (throw)

Podemos lançar nossos próprios erros usando throw, útil para validar entradas e impedir ações indesejadas.

📜 Exemplo: 
function dividir(a, b) {
  if (b === 0) {
    throw new Error("Divisão por zero não é permitida! ❌")
  }
  return a / b
}
try {
  console.log(dividir(10, 2)) // ✅ Ok
  console.log(dividir(10, 0)) // ❌ ERRO!
} catch (erro) {
  console.log("Erro capturado:", erro.message)
}

🔹 Saída:

// 5
// Erro capturado: Divisão por zero não é permitida! ❌

✔️ O erro foi tratado, evitando uma falha inesperada.

🧩 6. Diferentes tipos de erros no JavaScript

O JavaScript possui vários tipos de erros, como:

Erro Descrição
ReferenceError Variável não definida
TypeError Operação inválida para o tipo de dado.
SyntaxError Código com erro de sintaxe.
RangeError Valor fora do intervalo permitido.
📜 Exemplo: Capturando Erros Diferentes: 
try {
            let lista = [1, 2, 3]
            lista.length = -1 // ❌ ERRO: Tamanho de array negativo gera um RangeError.
          } catch (erro) {
  if (erro instanceof RangeError) {
    console.log("Erro de intervalo:", erro.message)
  } else {
    console.log("Outro erro:", erro.message)
  }
}

🔹 Saída:

// Erro de intervalo: Invalid array length
