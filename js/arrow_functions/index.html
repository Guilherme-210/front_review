Arrow Functions no JavaScript

O que são Arrow Functions?

As Arrow Functions são uma sintaxe mais curta para escrever funções no JavaScript, introduzidas no ES6. Elas utilizam a seta (=>) para definir funções de forma mais concisa.

Comparação de Sintaxes 

function normalSum(a, b) {
  return a + b;
}

const arrowSum = (a, b) => {
  return a + b;
};

const conciseArrowSum = (a, b) => a + b;

A primeira função segue a sintaxe tradicional, a segunda usa Arrow Function com um bloco de código e a terceira versão é ainda mais curta.

Exemplo Prático 

const towns = ['Prontera', 'Izlude', 'Payon', 'Alberta', 'Geffen', 'Morroc'];
const startingWithP = towns.filter(town => town[0] === 'P');
console.log(startingWithP);

Neste exemplo, usamos uma Arrow Function dentro do método filter para selecionar apenas as cidades que começam com a letra "P".
