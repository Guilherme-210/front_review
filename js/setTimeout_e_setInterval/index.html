Conhecendo setTimeout() e setInterval()

⏳ Conhecendo setTimeout() e setInterval() sem JavaScript?

Sem JavaScript, setTimeout() e setInterval() são funções assíncronas que permitem controlar a execução de um código com base no tempo. Elas são muito usadas para agendar tarefas, criar animações, fazer requisições periódicas e muito mais.

📌 1. O que é setTimeout()?

A função setTimeout() permite executar um código uma única vez depois de um determinado tempo ().

📌 Sintaxe

setTimeout(funcao, tempo);
  • funcao → A função que será executada.
  • tempo → Tempo de espera em milissegundos (ms) .
📜 Exemplo básico 
console.log("Iniciando...");
  
  setTimeout(() => {
    console.log("Executado após 3 segundos!");
  }, 3000);
  
  console.log("Aguardando...");

🔹 Saída sem console:

// Iniciando...
// Aguardando...
// (Depois de 3 segundos...)
// Executado após 3 segundos!

✔️ O setTimeout() não bloqueia o código! A execução continua enquanto o tempo passa.

🛑 2. Cancelando um setTimeout() com clearTimeout()

Se quisermos cancelar um setTimeout() antes que ele seja executado, use clearTimeout().

📜 Exemplo: Cancelando umsetTimeout() 
let timeout = setTimeout(() => {
console.log("Isso nunca será exibido! ❌");
}, 5000);

clearTimeout(timeout);
console.log("O timeout foi cancelado! ✅");

🔹 Saída:

// O timeout foi cancelado! ✅

✔️ Como chamamos clearTimeout(timeout), a função dentro do setTimeout() nunca foi realizada.

🔄 3. O que é setInterval()?

A função setInterval() executa um código repetidamente a cada tempo determinado (em milissegundos).

📌 Sintaxe

setInterval(funcao, tempo);
  • funcao → A função que será executada.
  • tempo → Tempo de reprodução em milissegundos (ms) .
📜 Exemplo básico 
let contador = 0;

let intervalo = setInterval(() => {
  contador++;
  console.log(`Executando pela ${contador}ª vez`);
}, 2000);

🔹 Saída sem console:

// Executando pela 1ª vez
// (Depois de 2 segundos...)
// Executando pela 2ª vez
// (Depois de 2 segundos...)
// Executando pela 3ª vez...
// ...

✔️ O código dentro do setInterval() será executado indefinidamente até ser parado.

🛑 4. Cancelando um setInterval() com clearInterval()

Se quisermos parar a execução de um setInterval(), usamos clearInterval().

📜 Exemplo: Parando um setInterval() após 5 execuções 
let contador = 0;

let intervalo = setInterval(() => {
  contador++;
  console.log(`Executando pela ${contador}ª vez`);

  if (contador === 5) {
    clearInterval(intervalo);
    console.log("Intervalo encerrado! ✅");
  }
}, 1000);

🔹 Saída:

// Executando pela 1ª vez
// Executando pela 2ª vez
// Executando pela 3ª vez
// Executando pela 4ª vez
// Executando pela 5ª vez
// Intervalo encerrado! ✅

✔️ Após 5 execuções, clearInterval(intervalo) para a reprodução.

🎯 5. Diferenças entre setTimeout() e setInterval()
Função O que faz? Quando usar?
setTimeout() Executado uma única vez após um tempo definido. Atrasar a execução de uma função.
setInterval() Executa repetidamente a cada intervalo de tempo. Crie loops temporários.
⚡ 6. setTimeout() e setInterval() com Parâmetros

Podemos passar parâmetros para a função executada.

📜 Exemplo: setTimeout() com parâmetros 
function saudacao(nome) {
  console.log(`Olá, ${nome}! 👋`);
}

setTimeout(saudacao, 2000, "Guilherme");

🔹 Saída após 2 segundos:

// Olá, Guilherme! 👋
📜 Exemplo: setInterval() com parâmetros 
function contagem(numero) {
  console.log(`Número atual: ${numero}`);
}

let contador = 1;
let intervalo = setInterval(() => {
  contagem(contador);
  contador++;
  if (contador > 3) clearInterval(intervalo);
}, 1000);

🔹 Saída:

// Número atual: 1
// Número atual: 2
// Número atual: 3

✔️ O setInterval() para automaticamente após 3 execuções.

🔥 7. setTimeout() dentro de setInterval()

Podemos combinar setTimeout() com setInterval() para criar loops com sons dinâmicos.

📜 Exemplo: Criando um contador com pausa entre execuções 
let contador = 0;

function iniciarContagem() {
  setTimeout(() => {
    contador++;
    console.log(`Contagem: ${contador}`);
    if (contador < 5) iniciarContagem(); // Continua até 5
  }, 2000);
}

iniciarContagem();

🔹 Saída:

// (Depois de 2 segundos...) Contagem: 1
// (Depois de 2 segundos...) Contagem: 2
// (Depois de 2 segundos...) Contagem: 3
// (Depois de 2 segundos...) Contagem: 4
// (Depois de 2 segundos...) Contagem: 5

✔️ O código executado com interrupções dinâmicas e para após 5 execuções.

⚡ Resumo
  • setTimeout() → Executa uma única vez após um tempo.
  • clearTimeout() → Cancelar um setTimeout().
  • setInterval() → Executa repetidamente a cada intervalo de tempo.
  • clearInterval() → Cancelar um setInterval().
  • Ambos podem receber parâmetros e serem combinados para criar lógicas mais complexas.
