Encadeamento Opcional com JavaScript

O que é Encadeamento Opcional?

O Encadeamento Opcional é uma funcionalidade do JavaScript que permite acessar propriedades aninhadas de um objeto sem causar erros caso alguma delas seja undefined ou null. Isso evita a necessidade de verificações repetitivas.

Exemplo usado na aula 
const user = {
  name: "John Doe",
  email: "doejohn@email.com",
  friends: [{
    name: "Mary",
    address: {
      street: "Some Street",
      number: 89
    }
  }],
  age: 42,
  phone: {
    countryCode: "+55",
    ddd: "22",
    number: "998765432"
  }
};

console.log(user.friends[0].phone?.ddd);
console.log(user?.brothers?.length);
console.log(user.brothers?.[5].name);

Neste exemplo, o operador ?. é utilizado para verificar se determinadas propriedades existem antes de acessá-las. Caso contrário, ele retorna undefined ao invés de lançar um erro.

Exemplo de treino 
const person = {
  name: "Alice",
  job: {
    title: "Developer",
    company: "TechCorp"
  }
};

console.log(person.job?.title); // "Developer"
console.log(person.address?.street); // undefined
