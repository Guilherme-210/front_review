Módulos Common.JS

O que é Módulos com Common.JS?

A utilização de importação e exportação usando o Common.JS é uma ferramenta a parte não suportada por padrão nos navegadores. Só que ele é a forma padrão de se trabalhar com módulos pelo Node.JS, mas mesmo no node ele não precisa ser utilizado necessariamente por haver outras ferramentas que podem ser utilizadas no lugar dele.

E ele pode ser totalmente substituído pela implementação nativa dos módulos do JavaScript, ao qual é preferível por serem ferramentas próprias da linguagem.

Exemplo sem importação de código 
function render1() {
  console.log('Renderizando a interface da aplicação...')
}

function store1() {
  console.log("Salvando as informações no banco de dados...")
}

console.log("Aplicação 1 iniciada.")
render1()
store1()
console.log("Aplicação finalizada.")

No exemplo a cima, é mais utilizado em códigos pequenos e de fácil manuseio, o qual acaba por não ter muito conteúdo.

Exemplo com importação de código 
//script.js
//requerimento de inportação
            
const render = require("./render.js")
const store = require("./store.js")

console.log("Aplicação 2 iniciada.")
render()
store()
console.log("Aplicação finalizada.")
//render.js
//Código de exportação da função render()

function render() {
  console.log('Renderizando a interface da aplicação...')
}

module.exports = render
//store.js
//Código de exportação da função store()

function store() {
  console.log("Salvando as informações no banco de dados...")
}

module.exports = store

Esse exemplo é mais utilizado quando há muito conteúdo, com o intuito de deixar o código mais legível e de fácil manutenção.
