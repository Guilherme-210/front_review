Recursos de Armazenamento do Navegador

Session Storage

O sessionStorage armazena dados temporários que são removidos ao final da sessão de navegação. A informação só está disponível enquanto a aba ou janela estiver aberta.

Local Storage

O LocalStorage armazena dados no navegador do usuário de forma persistente, sem expiração automática. Os dados são mantidos mesmo após o fechamento do navegador.

Cookies

Os Cookies são pequenos arquivos de texto armazenados no navegador do usuário. Eles lembram informações entre sessões e podem expirar após um período específico de tempo, acessíveis pelo cliente e servidor.
