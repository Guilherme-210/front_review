Operador de Coalescência Nula com JavaScript

O que é Operador de Coalescência Nula?

O Operador de Coalescência Nula (??) é um operador do JavaScript que retorna o lado direito apenas se o lado esquerdo for null ou undefined. Caso contrário, retorna o próprio valor da esquerda.

Exemplo usado na aula 

let a = 0

let b = a || 42

console.log({ a, b })

b = a ?? 42

console.log({a, b})

let c = false ?? 42

console.log({c})

Neste exemplo, a variável a é 0. Quando usamos ||, ele retorna 42 porque 0 é um valor "falsy". Já com ??, ele mantém 0, pois apenas null ou undefined acionam a substituição. No último caso, false ?? 42 retorna false, pois false não é null nem undefined.

Exemplo de treino 

let x = null ?? "Valor padrão"
console.log(x) // "Valor padrão"

let y = undefined ?? "Outro padrão"
console.log(y) // "Outro padrão"

let z = "Texto" ?? "Nada"
console.log(z) // "Texto"
