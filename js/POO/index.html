Programação Orientada a Objetos (POO) no JavaScript

📌O que é Programação Orientada a Objetos (POO)?

POO é um paradigma de programação baseado no conceito de objetos , que são estruturas que encapsulam dados (propriedades/atributos) e comportamentos (métodos).

Os quatro pilares do POO são:

  1. Encapsulamento 🏠 → Proteger dados dentro de uma estrutura.
  2. Abstração 🎭 → Ocultar detalhes desnecessários e expor apenas o essencial.
  3. Herança 👨‍👦 → Reutilizar código de uma classe em outra.
  4. Polimorfismo 🦾 → Modificar comportamentos herdados de forma diferente.

Agora vamos ver como isso funciona no JavaScript!

🛠️ Criando Objetos no JavaScript

Antes da introdução classno ES6, os objetos eram criados de formas mais simples, como objetos literários e funções construtoras .

1️⃣ Objeto Literal

A forma mais simples de criar um objeto é com {}: 

const pessoa = {
  nome: "Guilherme",
  idade: 25,
  falar: function() {
    console.log(`Olá, meu nome é ${this.nome}`);
  }
};

pessoa.falar(); // Saída: Olá, meu nome é Guilherme

Aqui, this referência ao próprio objeto pessoa.

2️⃣ Função Construtora

Antes das class, usávamos funções para criar "moldes" de objetos: 

function Pessoa(nome, idade) {
  this.nome = nome;
  this.idade = idade;
  this.falar = function() {
    console.log(`Meu nome é ${this.nome} e tenho ${this.idade} anos.`);
  };
}

const pessoa1 = new Pessoa("Ana", 30);
pessoa1.falar(); // Saída: Meu nome é Ana e tenho 30 anos.

A palavra-chave new cria uma nova instância do objeto com base na função Pessoa.

🔒 1. Encapsulamento

Encapsulamento protege os dados internos do objeto. Podemos usar # para tornar atributos privados: 

class ContaBancaria {
  #saldo; // Atributo privado

  constructor(saldoInicial) {
    this.#saldo = saldoInicial;
  }

  depositar(valor) {
    this.#saldo += valor;
    console.log(`Depósito de R$${valor} realizado!`);
  }

  getSaldo() {
    return this.#saldo;
  }
}

const conta = new ContaBancaria(1000);
conta.depositar(500);
console.log(conta.getSaldo()); 

// Saída: 1500
// console.log(conta.#saldo); ❌ ERRO! O atributo é privado.

O #saldo não pode ser acessado diretamente, apenas pelos métodos da classe.

🎭 2. Abstração

A abstração significa esconder detalhes internos e expor apenas o necessário. 

class Carro {
  constructor(modelo) {
    this.modelo = modelo;
  }

  ligar() {
    this.#checarCombustivel();
    console.log(`${this.modelo} está ligado!`);
  }

  #checarCombustivel() {
    console.log("Verificando combustível...");
  }
}

const carro = new Carro("Fusca");
carro.ligar();

// Saída: Verificando combustível...
//         Fusca está ligado!
// carro.#checarCombustivel(); ❌ ERRO! Método privado.

O método #checarCombustivel() está oculto do usuário.

👨‍👦 3. Herança

Herança permite que uma classe herde atributos e métodos de outra. 

class Animal {
  constructor(nome) {
    this.nome = nome;
  }

  fazerSom() {
    console.log("Som genérico de animal...");
  }
}

class Cachorro extends Animal {
  fazerSom() {
    console.log("Au au! 🐶");
  }
}

const rex = new Cachorro("Rex");
rex.fazerSom(); 

// Saída: Au au! 🐶

A classe Cachorro herdou Animal, mas sobrescreveu o método fazerSom().

🦾 4. Polimorfismo

Polimorfismo permite modificar métodos herdados sem mudar a interface da classe. 

class Forma {
  calcularArea() {
    return 0;
  }
}

class Quadrado extends Forma {
  constructor(lado) {
    super();
    this.lado = lado;
  }

  calcularArea() {
    return this.lado * this.lado;
  }
}

class Circulo extends Forma {
  constructor(raio) {
    super();
    this.raio = raio;
  }

  calcularArea() {
    return Math.PI * this.raio ** 2;
  }
}

const formas = [new Quadrado(4), new Circulo(3)];

formas.forEach(forma => {
  console.log(`Área: ${forma.calcularArea()}`);
});

// Saída: Área: 16
//         Área: 28.274333882308138

A função calcularArea() funciona diferente dependendo da classe.

⚡ Resumo
  • Objeto Literal → { chave: valor }
  • Função Construtora → function Pessoa()
  • Classe → class Pessoa
  • Encapsulamento → #atributoPrivado
  • Abstração → Esconder detalhes internos
  • Herança → class Filho extends Pai
  • Polimorfismo → Descrever métodos herdados

Com esses conceitos, você já pode começar a estruturar seus projetos usando POO no JavaScript! 🚀
