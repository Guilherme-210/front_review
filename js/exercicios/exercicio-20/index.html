Modelos de Calculadoras Com JavaScript

Calculadora OnClick

OnClick: É acionado quando um elemento é clicado. É comumente usado em botões, links ou qualquer elemento que possa receber um clique do usuário.

O calculo e executado automaticamente apos clicar no butão "Calcular"

Calculadora OnChange

OnChange: É acionado quando o valor de um elemento muda, como em campos de entrada de texto ou caixas de seleção. Ele é útil para detectar quando o usuário altera um valor.

O calculo e executado automaticamente apos sair do campo "2° número"
