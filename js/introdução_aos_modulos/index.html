Introdução aos Módulos

O que são Módulos?

Módulos são uma forma de dividir o código JavaScript em arquivos reutilizáveis. Com módulos, podemos separar funcionalidades específicas, tornando o código mais organizado e fácil de manter.

Exemplo de Uso 

// arquivo math.js
export function soma(a, b) {
  return a + b;
}

// arquivo main.js
import { soma } from "./math.js";
console.log(soma(2, 3)); // 5

No exemplo acima, o arquivo math.js exporta a função soma, e no main.js nós importamos essa função para utilizá-la.

Exemplo de Treino 

// arquivo saudacoes.js
export function saudacao(nome) {
  return `Olá, ${nome}!`;
}

// arquivo app.js
import { saudacao } from "./saudacoes.js";
console.log(saudacao("Guilherme"));
