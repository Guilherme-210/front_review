Desestruturação de Objetos e Arrays

O que é Desestruturação?

A desestruturação é uma funcionalidade do JavaScript que permite extrair dados de objetos e arrays de forma mais conveniente e legível.

Exemplo de Desestruturação de Objetos 

const person = {
  name: "Luke",
  job: "Farmer",
  parents: ["Anakin", "Padme"]
}

const { job, parents } = person;
console.log(job, parents);

No exemplo acima, estamos extraindo as propriedades job e parents diretamente do objeto person.

Exemplo de Desestruturação de Arrays 

const [father, mother] = parents;
console.log(father, mother);

Aqui, estamos desestruturando o array parents, atribuindo cada valor a variáveis individuais.

Uso de Desestruturação em Funções 

function createUser({ name, job, parents }) {
  const id = Math.floor(Math.random() * 9999);
  return {
    id,
    name,
    job,
    parents
  };
}

const luke = createUser(person);
console.log(luke);

A desestruturação pode ser usada como parâmetro de funções para facilitar a manipulação de objetos.
