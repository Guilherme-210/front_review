Classes e instâncias

📌 Classes e instâncias sem JavaScript

Se você quer entender a orientação de objetos no JavaScript, precisa conhecer classes e instâncias. Elas são uma base para criar objetos de forma organizada e reutilizáveis.

Bora entender isso de uma vez por todas! 🚀

🏛️ 1. O Que São Classes?

Uma classe é um molde para criar objetos. Pense em uma aula como uma receita de bolo : você pode seguir a receita várias vezes e criar vários bolos (instâncias) .

📜Criando uma aula no JavaScript

No JavaScript, usamos a palavra-chave classpara definir uma classe. 

class Carro {
  constructor(marca, modelo, ano) {
    this.marca = marca;
    this.modelo = modelo;
    this.ano = ano;
  }
}

Explicação:

  • class Carro {} → Defina uma classe Carro.
  • constructor(marca, modelo, ano) {} → O método especial constructor é chamado automaticamente quando criamos um carro novo.
  • this.marca = marca; → Definir uma propriedade da instância baseada no parâmetro recebido.
🚗 2. O Que São Instâncias?

Uma instância é um objeto criado a partir de uma classe.

📜 Criando uma Instância deCarro 
const meuCarro = new Carro("Toyota", "Corolla", 2022);
console.log(meuCarro);

🔹 Saída sem console:

// Carro { marca: 'Toyota', modelo: 'Corolla', ano: 2022 }

✔️ Agora temos um objeto real baseado no modelo Carro!

Podemos criar quantas instâncias quisermos usando a mesma classe: 

const carro1 = new Carro("Honda", "Civic", 2023);
const carro2 = new Carro("Ford", "Mustang", 1969);

console.log(carro1);
console.log(carro2);

🔹 Saída:

Carro { marca: 'Honda', modelo: 'Civic', ano: 2023 }
Carro { marca: 'Ford', modelo: 'Mustang', ano: 1969 }

✔️ Cada instância é um objeto independente de outra.

⚙️ 3. Adicionando métodos às aulas

Podemos adicionar funções dentro da classe para que todas as instâncias tenham acesso a elas.

📜 Exemplo: Adicionando um Método detalhes() 
class Carro {
  constructor(marca, modelo, ano) {
    this.marca = marca;
    this.modelo = modelo;
    this.ano = ano;
  }

  detalhes() {
    return `🚗 ${this.marca} ${this.modelo}, Ano: ${this.ano}`;
  }
}

const meuCarro = new Carro("Chevrolet", "Onix", 2024);
console.log(meuCarro.detalhes());

🔹 Saída:

// 🚗 Chevrolet Onix, Ano: 2024

✔️ O método detalhes() pode ser chamado em qualquer instância de Carro.

🏗️ 4. Herança:

Criando Classes Filhas Podemos criar uma classe filha que herda características da classe pai usando extends.

📜 Exemplo: Criando CarroEletricoque Herda deCarro 
class ContaBancaria {
  #saldo; // Propriedade privada

  constructor(nome, saldoInicial) {
    this.nome = nome;
    this.#saldo = saldoInicial;
  }

  depositar(valor) {
    this.#saldo += valor;
    console.log(`💰 Depósito de R$${valor} realizado.`);
  }

  verSaldo() {
    return `💵 Saldo de ${this.nome}: R$${this.#saldo}`;
  }
}

const conta = new ContaBancaria("Guilherme", 1000);
conta.depositar(500);
console.log(conta.verSaldo());

// console.log(conta.#saldo); // ❌ ERRO: Propriedade privada!

🔹 Saída:

// 💰 Depósito de R$500 realizado.
// 💵 Saldo de Guilherme: R$1500

🚀 Resumo Rápido
Conceito Explicação
Classe Um molde para criar objetos.
Instância Um objeto criado a partir de uma classe.
Construtor Função especial que roda ao criar uma instância.
Método Uma função dentro da classe que pode ser usada nas instâncias.
Herança Criar uma classe baseada em outra, reaproveitando código.
Propriedades Privadas Usando #, criamos atributos protegidos da classe.
