Tipos de Export no ESM

Exportação na mesma linha

O arquivo inline.js permite exportar vários valores de um módulo e importá-los pelo nome exato.

📜 Exemplo: 
export function inline() {
  console.log("Export nomeado inline")
}

export default function () {
  console.log("Export default inline")
}

Este arquivo fornece duas maneiras de usar suas funções:

Uma através de uma importação nomeada específica (inline)

Uma através de uma importação padrão (default), que pode ser renomeada no momento da importação.

Exportação usando multiplas linhas

O arquivo non-inline.js exporta um único valor, que pode ser importado com qualquer nome.

📜 Exemplo: 
function group() {
  console.log("Export nomeado não-inline (agrupado)")
}

function a() {}
function b() {}
function c() {}
function d() {}

function exportDefault() {
  console.log("Export default não-inline")
}

export { group, a, b, c, d }

export default exportDefault

Neste codigo foram definidas 6 fonções ao qual 5 delas foram nomeadas e exportadas juntas export { group, a, b, c, d } enquanto uma foi criada e exportada como exportDefault(), Isso permite que quem importar o módulo use qualquer nome para se referir a essa função.

Arquivo de importação para cada elemento

O arquivo script.js demonstra diferentes formas de importar e usar módulos em JavaScript, focando em importações nomeadas e padrão (default).

📜 Exemplo: 
// import { inline } from "./inline.js"
import { inline as i } from "./inline.js"
import defaultInline from "./inline.js"
import exportDefault, { group, a, b, c, d } from "./non-inline.js"

i()
defaultInline()

group()
exportDefault()

Tanto na importação { inline }, quanto na importação { inline as i } importam a mesma função, so que ao usao o "as" vc modifica o nome da função importada para uso dentro do seu arquivo, a fim de evitar comflitos.

O código (import defaultInline from "./inline.js").
Importa o padrão (default) do arquivo ./inline.js, e atribui essa exportação à variável defaultInline.

O código (import exportDefault, { group, a, b, c, d } from "./non-inline.js")
Importa o padrão (default) do arquivo ./non-inline.js e a atribui à variável (exportDefault), e importa também as exportações nomeadas (group, a, b, c e d) do mesmo arquivo.
