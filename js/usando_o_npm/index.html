Guia do NPM

O que é o NPM?

O NPM (Node Package Manager) é o gerenciador de pacotes padrão para o Node.js. Ele permite instalar, compartilhar e gerenciar dependências de projetos JavaScript.

Como instalar o NPM?

O NPM já vem instalado com o Node.js. Para verificar se ele está instalado, use o seguinte comando no terminal: 

npm -v
Comandos básicos

Instalar um pacote:

npm install nome-do-pacote

Instalar um pacote globalmente:

npm install -g nome-do-pacote

Atualizar pacotes:

npm update

Remover um pacote:

npm uninstall nome-do-pacote
O que é o ESLint?

O ESLint é uma ferramenta que analisa o código JavaScript/TypeScript para encontrar erros e garantir boas práticas. Ele ajuda a manter um código padronizado e evita bugs.

Instalação:

npm install eslint --save-dev

Inicializar configuração:

npx eslint --init

Corrigir erros automaticamente:

npx eslint . --fix
O que é o Lodash?

O Lodash é uma biblioteca JavaScript que fornece funções utilitárias para trabalhar com arrays, objetos, strings e muito mais. Ele ajuda a escrever código mais limpo e eficiente.

Instalação:

npm install lodash

Importação no código:

const Lodash = require('lodash'); // CommonJS
import Lodash from 'lodash'; // ES Modules

Exemplo de uso (remover valores falsy de um array): 

const arr = [0, 1, false, 2, "", 3, null, undefined, NaN];
console.log(Lodash.compact(arr)); // [1, 2, 3]
