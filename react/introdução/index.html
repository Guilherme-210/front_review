📌 Introdução ao React

🤔 O que é o React?

React (ou React.js) é uma biblioteca JavaScript para criar interfaces de usuário, mantida pelo Facebook.

“Mas pera... é um framework ou biblioteca?”

React é uma biblioteca focada só na parte de visualização (view) da sua aplicação. Ele não se mete com rotas, requisições, nem banco de dados. É só a “carinha do app”.

🎯 Qual é o objetivo do React?

Facilitar o desenvolvimento de interfaces interativas e reutilizáveis, de forma rápida, dinâmica e eficiente.

🧱 Conceito-chave: Componentes

React é baseado no conceito de componentes.

Pensa em componentes como pequenas peças de LEGO: cada peça representa um pedaço da sua interface (um botão, uma barra de navegação, um card de produto, etc.).

Vamos criar um componente básico de título.

index.jsx 
function OlaMundo() {
  return <h1>Olá, mundo!</h1>;
}

Esse é um componente funcional. Ele retorna um elemento JSX (já falo disso 👇) que será renderizado na tela.

💡 JSX - JavaScript + XML

JSX é uma sintaxe que parece HTML, mas é usada dentro do JavaScript.

Com ela, você escreve assim:
index.jsx 
const elemento = <h1>Olá, React!</h1>;

🔹 Por baixo dos panos, o JSX vira algo assim:

index.js 
React.createElement('h1', null, 'Olá, React!');

✔️ JSX é mais legível e intuitivo.

⚙️ Como o React funciona?

Ele usa um conceito chamado DOM Virtual (Virtual DOM).

Quando algo muda, o React compara o que mudou e atualiza só aquela parte da tela, sem recarregar tudo.

Isso deixa a aplicação mais rápida e eficiente.

🔄 Estado e Interatividade (useState)

React não é só pra mostrar HTML bonitinho. Ele reage (daí o nome) a mudanças de estado.

Exemplo com useState (hook pra guardar dados):
local ou arquivo 
import { useState } from 'react';

function Contador() {
  const [contador, setContador] = useState(0);

  return (
    <div>
      <p>Você clicou {contador} vezes</p>
      <button onClick={() => setContador(contador + 1)}>Clique aqui</button>
    </div>
  );
}

🔄 A cada clique, o valor muda e o React atualiza só o texto <p>.

📦 Por que usar React?
  • Componentes reutilizáveis
  • Atualizações rápidas com DOM Virtual
  • Comunidade gigante e cheia de pacotes úteis
  • Funciona bem com outras libs (Axios, React Router, etc.)
  • Muito usado no mercado (empregabilidade 🔥)

🚀 Conclusão

React é uma ferramenta poderosa que te ajuda a criar interfaces de forma modular, interativa e eficiente.

Você escreve menos código repetitivo, separa tudo em pedacinhos e ainda ganha performance no processo.
